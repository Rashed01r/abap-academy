## Implemented improvements

- All 24 activities have short bilingual what/why introductions and explicit essential concept explanations. Original detailed prose/practice/references remain in Go Deeper. Essential teaching is selectable in Simple Mode rather than confined to optional token details.
- 81 essential concepts have stable lesson-qualified IDs, English/Arabic names, objective references, level/difficulty, recommended prior lesson, essential priority, example/explanation targets, demonstration and assessment links. Every concept has optional misconception practice without awarding XP or altering the existing 34 assessments.
- Nine selectable alternative anatomy examples: ELSEIF ranges, DO accumulation, structured APPEND, structured LOOP AT, EXIT, READ by index, ascending SORT, SORTED declaration and HASHED declaration. Seven execute in the supported interpreter; the two declarations are reference-only and never offer trace execution. Anatomy groups are organized by meaning and checked against source.
- Four interactive diagram families: interpreter-backed decision branches and skip/stop timelines; explicitly conceptual instance/static ownership and report event paths. Guided artifact relationships across seven advanced lessons now use navigable node-and-arrow diagrams, stacking vertically in narrow panels. Existing table, memory, lookup, mutation, SQL and Dictionary models remain.
- Knowledge-check review found extra requirements beyond the headline examples: initial integer zero, CLASS-DATA, normal report ending versus guaranteed cleanup, VALUE replacement and explicit SQL result ordering. These now have beginner-facing teaching. Dictionary controls also explain CHAR/NUMC/INT4, fixed-value policy and stable identity without inventing a database constraint.
- An advisory journey groups the nine paths into beginner/intermediate/advanced, explains the progression and offers a direct syntax starting point. Completed activities offer a real next lesson. Every implemented topic stays freely accessible.
- Permanent prebuild coverage/review-drift gate, independent visualizer/knowledge requirements, adversarial validation tests, generated reports and [authoring gates A–H](EDUCATIONAL_QUALITY.md). Quality records are separate from student records.
